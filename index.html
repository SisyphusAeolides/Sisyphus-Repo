Sisyphus Package Repository

A signed Arch Linux x86_64 package repository maintained by SisyphusAeolides.

Use with pacman

Add this repository to /etc/pacman.conf:

[sisyphus]
SigLevel = Required DatabaseRequired
Server = https://cdn.jsdelivr.net/gh/SisyphusAeolides/Sisyphus-Repo@main/$arch
Server = https://raw.githubusercontent.com/SisyphusAeolides/Sisyphus-Repo/main/$arch

Install the signing key, refresh the databases, and install packages:

sudo pacman-key --add keys/sisyphus-repo-2026.asc
sudo pacman-key --lsign-key BB4B20152E487BEC32051E1C1466A088F999E0C8
sudo pacman -Syy
sudo pacman -S iwchaos blerust ccze-rs libinput-rs tuned-rs
